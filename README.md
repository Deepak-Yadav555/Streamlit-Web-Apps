# 📈 Stock Market Dashboard

A real-time stock analysis web application built using **Python** and **Streamlit**. 
It fetches live data from Yahoo Finance and visualizes stock price trends using interactive charts.

## 🚀 Features
- **Live Stock Data:** Fetches real-time data for any stock (e.g., RELIANCE.NS, AAPL).
- **Interactive Charts:** Line charts to track Close Price trends over time.
- **Fundamental Data:** Displays Open, High, Low, and Close prices for the current day.
- **Data Table:** View and scroll through historical data.

## 🛠️ Tech Stack
- **Python** (Programming Language)
- **Streamlit** (Web Framework)
- **yfinance** (Stock Market Data API)
- **Pandas** (Data Manipulation)
